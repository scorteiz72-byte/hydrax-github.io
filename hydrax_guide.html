01

Launch the application

Open HydraX.exe. No separate launcher is required.

Keep the runtime folder next to the executable. The EXE will not start correctly on its own without this folder.
02

Sign in

  1. When the splash screen appears, enter a username and password.
  2. Both are stored locally on this PC. The username appears in the panel sidebar; the password unlocks the panel.
  3. Select Remember log in if you want the username pre-filled next time.
03

Activate your licence

  1. The activation window displays your hardware ID.
  2. Press COPY and provide the ID to Blizly.
  3. Paste the returned licence key into the activation window.

The key is tied to that machine and is stored in runtime\license.dat.

04

Complete the setup wizard

The setup wizard appears every time the application launches.

YES · Hardware bridge

Choose this if you use a Waveshare RP2350 or Adafruit RP2040 HID bridge.

NO · Software controller

Choose this for the software virtual controller (ViGEmBus).

Closing the wizard counts as NO. You can change the selection later under Input → Hardware bridge.

05

Start the engine

When the panel opens, press START ENGINE in the top-right corner. Allow a moment for the model to load.

06

In-game controls

Right mouse (hold)

Aim Assist activation.

G

Triggerbot activation.

END

Panic key — stops everything.

Rebinding

Change keys in Aim Assist → Activation or Input → Panic control. The bind dialog also accepts mouse buttons.

07

Mouse and virtual controller

Virtual controller

The reference output is the ViGEm virtual pad. It is created when the engine starts and remains connected for the session. The sticks return to neutral when aim is not active.

Mouse mode

Mouse on the Input page is the alternative mode. It uses synthetic cursor movement without a virtual pad. The supplied guide describes it for games that do not respond to the virtual pad.

The setup wizard's virtual controller option uses ViGEmBus. The guide identifies the RP2350 / RP2040 HID bridge as the hardware alternative.
08

How the system works

  1. Capture: obtains a square field of view around the screen centre, using GPU capture through DXCam or a GDI DIB path.
  2. Detect: the YOLO session returns detection boxes and confidence values.
  3. Track: IoU and centre matching maintain target identity between frames, estimate movement and handle temporary occlusion.
  4. Aim: the predicted aim point is eased using a curve, speed cap, reaction window and micro-jitter setting.
09

Safety and focus behaviour

  • The supplied documentation describes screen-pixel capture, with no game-memory read or write, hooks or injection.
  • Focus gate: input is active only while the game window is in the foreground.
  • The panic key remains armed.
  • The overlay is click-through and does not interact with the game process.
  • Hold-to-aim: no input is sent unless the activation key is held.
  • The HUD displays a field-of-view ring and crosshair. The guide says it does not display player boxes, tracers, labels or a telemetry panel.
Use software only where permitted by the game and its rules. A screen-only design does not guarantee that a game's anti-cheat or terms of service permit it.
10

Explore the panel pages

Each page has a master switch at the top, with its settings underneath.

Aim Assist

Field-of-view ring, aim point, smoothing, activation mode and telemetry.

Triggerbot

Fire key, reaction window and burst behaviour.

Controls

Mouse and keyboard behaviour, plus panic control.

Hardware

Virtual controller (DS4 / Xbox), mouse and RP2350 HID bridge.

Overlay

Field-of-view ring, crosshair shape, colours and thickness.

Colours

Live colour settings throughout the panel. Factory reset restores the blue-glass palette.

License

Build identity and licence key.

11

Quick tips

  • Field of view: the documented range is 0–350 px.
  • Smoothing: 0 is described as immediate movement; 100 as gradual movement. The supplied guide mentions 10–30 as a reference range.
  • Crosshair shake: the guide suggests reviewing reaction-window and micro-jitter settings.
  • Performance: if the game stutters, the guide suggests Standard capture and disabling rainbow overlay animations.
  • Display mode: the HUD is described as re-arming after a fullscreen / windowed display-mode change.
  • Controller setup: the guide lists ViGEmBus as a requirement for the virtual controller option.
  • Streaming: the overlay can be switched off from the Overlay page.
12

Configuration and reset

Settings are written to runtime\config.json whenever they change.

Full configuration reset

  1. Close HydraX.
  2. Delete the following files:
runtime\config.json
runtime\ui_theme.json
runtime\login.json
  1. Start HydraX again.
Inside the panel, Colours → Reset to factory resets only the palette and glass toggles. It keeps the session name and the rest of the configuration intact.

System requirements

Windows 10 / 11 (64-bit) and a DirectML-capable GPU or a capable CPU.
